# Self-Hosting LearnHouse

LearnHouse can be self-hosted on your own infrastructure using the **LearnHouse CLI**. The CLI handles everything from initial setup to ongoing maintenance, including Docker Compose generation, environment file management, service orchestration, backups, and health checks.

## Quick Start

Make sure you have **Docker** with the Compose v2 plugin and **Node.js 22+** installed (see [Requirements](/self-hosting/installation/requirements)), then run:

```bash
npx learnhouse@latest setup
```

The interactive setup wizard walks you through domain configuration, database settings, admin credentials, and optional features. At the end it offers to start LearnHouse and waits until it is ready. If you skipped that, start it with:

```bash
npx learnhouse start
```

LearnHouse is available at **http://localhost** (or your configured domain). Log in with the admin credentials you provided during setup. [Quick Install](/self-hosting/installation/quick-install) covers the one-line installers, non-interactive setup and checks.

<Callout type="info">
The CLI generates `docker-compose.yml`, `.env`, and reverse proxy configuration for you. You do not need to write or maintain these files manually.
</Callout>

### Verify the installation

```bash
npx learnhouse doctor
```

### Common management commands

```bash
npx learnhouse stop       # Stop all services
npx learnhouse start      # Start all services
npx learnhouse logs       # Stream container logs
npx learnhouse config     # View current configuration
npx learnhouse backup     # Back up the database, .env and uploaded content
npx learnhouse update     # Update to the latest version
npx learnhouse doctor     # Diagnose issues
```
