# Key Concepts

This page introduces the core building blocks of LearnHouse and how they fit together.

## Organizations

An **organization** is the top-level tenant in LearnHouse. Each organization has its own courses, users, settings, and branding. A self-hosted Community instance runs a single organization. Hosting several organizations on one instance (multi-tenancy) requires the Enterprise Edition or LearnHouse Cloud.

## Courses

A **course** is the primary unit of content. Every course contains one or more **chapters**, and each chapter contains one or more **activities**. Think of a course as a structured curriculum that guides learners from start to finish.

## Activities

An **activity** is a single piece of learning content inside a chapter. The main activity types are:

- **Dynamic pages**: block-based pages built with the LearnHouse editor, with quizzes, flashcards, code challenges and more.
- **Videos**: uploaded videos or YouTube links.
- **Documents**: PDFs shown in a built-in viewer.
- **Assignments**: graded tasks, including graded quizzes, that learners submit.

Markdown, embed and Library resource activities are also available, and SCORM activities on the Enterprise Edition. See [Chapters & Activities](/platform/courses/chapters-and-activities).

Chapters can be released over time with [Drip Content](/platform/courses/drip-content), and chapters and activities can be locked to signed-in users or user groups.

## Library

The **Library** is where an organization keeps its content in folders, like a shared drive. A folder can hold courses, podcasts, communities, boards, playgrounds and media files. See [Library](/platform/courses/library).

## Learning paths

A **learning path** is an ordered set of courses that learners follow from start to finish, with required and elective courses and its own certificate. The courses stay normal courses. See [Learning Paths](/platform/paths).

## Trails

A **trail** tracks a learner's progress through a course. It records completed activities, quiz results, and overall advancement. Teachers can use trail data to monitor student performance, while learners can see their own progress and pick up where they left off.

## Editor

LearnHouse includes a block-based **WYSIWYG editor** for authoring dynamic page activities. The editor supports many block types (text, headings, images, code, callouts, quizzes, embeds, and more). Every save creates a version you can restore, and if two teachers save the same page, LearnHouse asks which version to keep. With [dynamic content](/platform/editor/dynamic-content), one page can read differently for every learner, and templates let you reuse blocks and pages.
