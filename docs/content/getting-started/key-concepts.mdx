# Key Concepts

This page introduces the core building blocks of LearnHouse and how they fit together.

## Organizations

An **organization** is the top-level tenant in LearnHouse. Each organization has its own courses, users, settings, and branding. A self-hosted Community instance runs a single organization. Hosting several organizations on one instance (multi-tenancy) requires the Enterprise Edition or LearnHouse Cloud.

## Courses

A **course** is the primary unit of content. Every course contains one or more **chapters**, and each chapter contains one or more **activities**. Think of a course as a structured curriculum that guides learners from start to finish.

## Activities

An **activity** is a single piece of learning content inside a chapter. LearnHouse supports several activity types:

- **Dynamic pages**: block-based pages built with the LearnHouse editor.
- **Videos**: hosted video content with playback tracking.
- **Documents**: PDF and other document uploads for reference material.
- **Quizzes**: assessments that test learner understanding and feed into progress tracking.

## Library

The **Library** is where an organization keeps its content in folders, like a shared drive. A folder can hold courses, podcasts, communities, boards, playgrounds and media files. Use folders to group related courses into a learning path or a program. See [Library](/platform/courses/library).

## Trails

A **trail** tracks a learner's progress through a course. It records completed activities, quiz results, and overall advancement. Teachers can use trail data to monitor student performance, while learners can see their own progress and pick up where they left off.

## Editor

LearnHouse includes a block-based **WYSIWYG editor** for authoring dynamic page activities. The editor supports many block types (text, headings, images, code, callouts, embeds, and more) and real-time collaborative editing, so several authors can work on the same page at once.
