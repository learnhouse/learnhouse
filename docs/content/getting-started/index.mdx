# Introduction

LearnHouse is an open-source learning platform. You create courses in a block editor, invite learners, and run your
academy on LearnHouse Cloud or on your own servers. Everything it does is also available through an API, so you can
build your own experience on top.

## Frequently asked questions

### What is LearnHouse?

LearnHouse is an open-source learning management system (LMS) for running an online academy: a block editor for
courses, AI tutoring, assignments and grading, certificates, payments and communities. It runs on LearnHouse Cloud or
on your own servers.

### Is LearnHouse free?

The platform is open source (AGPL-3.0) and free to self-host. LearnHouse Cloud has a Free plan and paid plans.

### Can developers build on LearnHouse?

Yes. LearnHouse has a [REST API](/developers/api), a typed [TypeScript SDK](/developers/sdk), and
[React](/developers/react) and [Vue](/developers/vue) components that render courses inside your own app. You can use
it as a [headless LMS](/developers).
