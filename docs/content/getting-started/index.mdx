# Getting Started

LearnHouse is an open-source learning management system for creating and delivering courses.

This section takes you from nothing to a working LearnHouse setup, on our managed cloud platform or on your own servers.

## What you will learn

- **[Quickstart](/getting-started/quickstart)**: get up and running in minutes with LearnHouse Cloud or the self-hosted CLI.
- **[Cloud vs Self Hosting](/getting-started/cloud-vs-self-hosting)**: compare the trade-offs so you can pick the right deployment model.
- **[Key Concepts](/getting-started/key-concepts)**: the core building blocks, including organizations, courses, activities, collections, trails, and the editor.

<Callout>
If you already know how you want to deploy, jump straight to the [Quickstart](/getting-started/quickstart).
</Callout>

## Next steps

Once you have a running instance and understand the basics, explore the rest of the documentation:

- [Platform Guide](/platform): courses, the editor, AI features, and user management.
- [Self Hosting](/self-hosting): configuration, content storage, AI setup, and organization hosting modes.
- [Developers](/developers): architecture overview, API reference, and contributing guide.
