# Environment Variables

This page covers two things: the environment variables the CLI itself reads, and the `.env` file it generates for a Community installation. For every variable the LearnHouse services read, see the [self-hosting reference](/self-hosting/configuration/environment-variables).

## Variables the CLI reads

| Variable | Description |
| --- | --- |
| `LEARNHOUSE_DIR` | Installation directory to act on. Same as the global `--dir` option. |
| `LEARNHOUSE_DOCKER_BIN` | Docker executable to call instead of `docker` on your `PATH`, for example an absolute path or a Docker-compatible CLI. A value ending in `.js`, `.mjs` or `.cjs` is run with the current Node.js. |
| `LEARNHOUSE_ADMIN_PASSWORD` | Admin password for `setup`, instead of `--admin-password` |
| `LEARNHOUSE_EXTERNAL_DB` | External PostgreSQL connection string for `setup`, instead of `--external-db` |
| `LEARNHOUSE_EXTERNAL_REDIS` | External Redis connection string for `setup`, instead of `--external-redis` |
| `LEARNHOUSE_LICENSE_KEY` | Enterprise license key for `setup`, instead of `--license` |
| `LEARNHOUSE_CF_API_TOKEN` | Cloudflare API token for Enterprise DNS-01 certificates, instead of `--cf-api-token` |
| `LEARNHOUSE_NO_UPDATE_CHECK` | Any value turns off the check for a newer CLI version |
| `NO_UPDATE_NOTIFIER` | Same as `LEARNHOUSE_NO_UPDATE_CHECK` |
| `CI` | Any value turns off the update check |
| `LEARNHOUSE_DEBUG` | Any value prints the stack trace when a command fails with an unexpected error |

Passing secrets through the environment keeps them out of the process list and your shell history. When both a flag and its variable are set, the flag wins.

```bash
LEARNHOUSE_ADMIN_PASSWORD=secretpass123 npx learnhouse setup --ci --domain example.com --admin-email admin@yourdomain.com
```

## Generated `.env` file

The CLI writes a `.env` file to the installation directory during setup, readable only by your user. You can edit it with `npx learnhouse env` or by hand, then restart services. Re-running setup keeps the existing secrets (`NEXTAUTH_SECRET`, `LEARNHOUSE_AUTH_JWT_SECRET_KEY`, `COLLAB_INTERNAL_KEY`) and the database password.

### Domain & Hosting

| Variable | Description | Example |
| --- | --- | --- |
| `LEARNHOUSE_DOMAIN` | Hostname, with the port when it is not the default | `localhost` |
| `HTTP_PORT` | Port the reverse proxy publishes | `80` |
| `NEXT_PUBLIC_LEARNHOUSE_API_URL` | Public API URL | `http://localhost/api/v1/` |
| `NEXT_PUBLIC_LEARNHOUSE_BACKEND_URL` | Backend URL | `http://localhost/` |
| `NEXT_PUBLIC_LEARNHOUSE_DOMAIN` | Public domain | `localhost` |
| `NEXT_PUBLIC_LEARNHOUSE_TOP_DOMAIN` | Last two labels of the domain | `localhost` |
| `NEXT_PUBLIC_LEARNHOUSE_MULTI_ORG` | Multi-org mode | `False` |
| `NEXT_PUBLIC_LEARNHOUSE_DEFAULT_ORG` | Default organization slug | `default` |
| `NEXT_PUBLIC_LEARNHOUSE_HTTPS` | HTTPS enabled | `False` |
| `NEXTAUTH_URL` | Public base URL | `http://localhost` |

### Database & Redis

| Variable | Description | Example |
| --- | --- | --- |
| `LEARNHOUSE_SQL_CONNECTION_STRING` | PostgreSQL connection | `postgresql://learnhouse:<password>@db:5432/learnhouse` | {/* gitleaks:allow */}
| `LEARNHOUSE_REDIS_CONNECTION_STRING` | Redis connection for the API | `redis://redis:6379/learnhouse` |
| `LEARNHOUSE_REDIS_URL` | Redis connection for the collaboration server | `redis://redis:6379` |
| `POSTGRES_USER` | Database user (in-container database only) | `learnhouse` |
| `POSTGRES_PASSWORD` | Database password (in-container database only) | Generated |
| `POSTGRES_DB` | Database name (in-container database only) | `learnhouse` |

### Security & Setup

| Variable | Description | Example |
| --- | --- | --- |
| `NEXTAUTH_SECRET` | Auth secret | Generated |
| `LEARNHOUSE_AUTH_JWT_SECRET_KEY` | JWT signing key | Generated |
| `LEARNHOUSE_COOKIE_DOMAIN` | Cookie domain | `.localhost`, or `.<top domain>` |
| `LEARNHOUSE_INITIAL_ADMIN_EMAIL` | First admin email | Set during setup |
| `LEARNHOUSE_INITIAL_ADMIN_PASSWORD` | First admin password | Set during setup |
| `LEARNHOUSE_INITIAL_ORG_NAME` | First organization name | Set during setup |
| `LEARNHOUSE_INITIAL_ORG_SLUG` | First organization slug | `default` |
| `COLLAB_INTERNAL_KEY` | Shared key between the API and the collaboration server | Generated |

### Application

| Variable | Description | Example |
| --- | --- | --- |
| `LEARNHOUSE_PORT` | Internal API port | `9000` |
| `LEARNHOUSE_DEVELOPMENT_MODE` | Development mode | `False` |
| `LEARNHOUSE_LOGFIRE_ENABLED` | Written for compatibility; not read by the current runtime | `False` |
| `NEXT_PUBLIC_COLLAB_URL` | WebSocket URL of the collaboration server | `ws://localhost/collab` |

### AI

| Variable | Description | Example |
| --- | --- | --- |
| `LEARNHOUSE_IS_AI_ENABLED` | Enable AI features | `True` / `False` |
| `LEARNHOUSE_GEMINI_API_KEY` | Gemini API key (only when AI is enabled) | Your API key |

### Email

Written only when you enable email during setup.

| Variable | Description | Example |
| --- | --- | --- |
| `LEARNHOUSE_EMAIL_PROVIDER` | Email provider | `resend` / `smtp` |
| `LEARNHOUSE_SYSTEM_EMAIL_ADDRESS` | From address | `noreply@yourdomain.com` |
| `LEARNHOUSE_RESEND_API_KEY` | Resend API key | Your API key |
| `LEARNHOUSE_SMTP_HOST` | SMTP host | `smtp.gmail.com` |
| `LEARNHOUSE_SMTP_PORT` | SMTP port | `587` |
| `LEARNHOUSE_SMTP_USERNAME` | SMTP username | `user@yourdomain.com` |
| `LEARNHOUSE_SMTP_PASSWORD` | SMTP password | Your password |
| `LEARNHOUSE_SMTP_USE_TLS` | Enable TLS | `True` / `False` |

### Content Storage

| Variable | Description | Example |
| --- | --- | --- |
| `LEARNHOUSE_CONTENT_DELIVERY_TYPE` | Storage type | `filesystem` / `s3api` |
| `LEARNHOUSE_S3_API_BUCKET_NAME` | S3 bucket name (S3 only) | `my-bucket` |
| `LEARNHOUSE_S3_API_ENDPOINT_URL` | S3 endpoint (S3 only, optional for AWS) | `https://s3.amazonaws.com` |

### OAuth

Written only when you enable Google OAuth during setup.

| Variable | Description | Example |
| --- | --- | --- |
| `LEARNHOUSE_GOOGLE_CLIENT_ID` | Google OAuth client ID | Your client ID |
| `LEARNHOUSE_GOOGLE_CLIENT_SECRET` | Google OAuth client secret | Your secret |

<Callout type="info">
The generated `docker-compose.yml` also sets `HOSTNAME=0.0.0.0` and `LEARNHOUSE_API_URL=http://localhost:9000` for the app container. The setup wizard does not write `LEARNHOUSE_SSL`; add `LEARNHOUSE_SSL=true` yourself when you serve LearnHouse over HTTPS, so links the API builds without a request to copy the scheme from (for example in background emails) use `https://`. See [SSL & Domain](/self-hosting/configuration/ssl).
</Callout>
