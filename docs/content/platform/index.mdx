# Platform Overview

This section documents the features of the LearnHouse platform for learners, teachers and administrators.

## Sections

- **[Courses](/platform/courses)**: Create courses by hand, with AI or by importing them, then organize chapters, activities, settings and your content library.
- **[Learning Paths](/platform/paths)**: Ordered sets of courses with required and elective courses, guided order and a path certificate.
- **[Editor](/platform/editor)**: A block-based editor for lessons, with version history and AI help.
- **[Assignments](/platform/assignments)**: Graded work made of quizzes, forms, file uploads, code challenges and short answers, with auto-grading and analytics.
- **[Code Execution](/platform/code-execution)**: Code Playground blocks that run learner code in 30 languages, with auto-graded test cases.
- **[Playgrounds](/platform/playgrounds)**: Interactive pages that AI builds from your description (separate from Code Playground blocks).
- **[Communities](/platform/discussions)**: Discussion spaces where members post, reply, upvote and react.
- **[Messages](/platform/messages)**: Direct messages, group chats, course announcements and AI agents that answer from your courses.
- **[Boards](/platform/boards)**: Shared real-time canvases for live classes and group work.
- **[Podcasts](/platform/podcasts)**: Audio shows with episodes and an RSS feed.
- **[Calendar](/platform/calendar)**: A personal calendar of deadlines, chapter releases, new episodes and live sessions.
- **[Certifications](/platform/certifications)**: Certificates for learners who complete a course or a learning path, each with a public verification page.
- **[Analytics](/platform/analytics)**: Dashboards for your organization, each course and each learner. Self-hosted instances need the Enterprise Edition.
- **[Search](/platform/search)**: One search across your organization, plus the command palette and keyboard shortcuts.
- **[Payments](/platform/payments)**: Sell courses with Stripe through offers, a store and checkout. Self-hosted instances need the Enterprise Edition.
- **[AI](/platform/ai)**: AI features for teachers and learners that work from your own content.
- **[Users & Access](/platform/users)**: Members, invites, roles, user groups, sign-in and two-factor authentication.
- **[Organizations](/platform/organizations)**: Settings, branding, landing page, custom domains, SEO and plans.
- **[Automations](/platform/automations)**: Webhooks and a Zapier API that send LearnHouse events to your own systems.
