# Editor

Dynamic Page activities are written in a block-based editor. You build a page by stacking blocks (text, images, quizzes, code challenges, embeds) and rearranging them.

To open it, go to a course in the dashboard, open the **Content** tab and click **Edit Page** on a Dynamic Page activity. The editor only works on a desktop browser. On a phone it shows **Desktop Only**.

## Writing

- **Slash menu**: type `/` to insert any block. See [Blocks](/platform/editor/blocks) for the full list.
- **Toolbar**: paragraph and headings, bold, italic, underline, strikethrough, inline code, links, lists, code blocks and table controls.
- **Paste or drop files**: images, MP4 or WebM videos and PDFs dropped or pasted into the page are uploaded and become blocks.
- **Drag handle**: hover a block and drag the handle on its left to move it.
- **Activity switcher**: jump to another activity of the same course without leaving the editor. If you have unsaved changes, you are asked to save first.

## Saving and version history

Click **Save** to save the page. Every save creates a new version of the activity.

Click the history button next to **Save** to open **Version History**. You can preview any saved version and click **Restore this version** to go back to it. Up to 20 versions are kept per activity.

If another teacher saved the same page while you were editing, the save button turns amber and LearnHouse asks which version to keep:

| Option | What happens |
| --- | --- |
| **Keep my version** | Your content replaces theirs. |
| **Keep their version** | Your unsaved changes are dropped. |
| **Keep both** | Your content is kept, with their changes added below. |

<Callout>
On LearnHouse Cloud, Version History needs the Pro plan or higher. Self-hosted instances do not apply plan restrictions to it.
</Callout>

## AI Editor

Click **AI Editor** in the editor header to open a chat panel that edits the page with you. Select a block to focus the request on it, or ask about the whole page. Quick actions include **Improve writing**, **Add examples**, **Simplify**, **Expand**, **Add quiz**, **Translate**, **Add summary**, **Add tip** and **Add definition**.

Each message uses one AI credit. See [AI for Teachers](/platform/ai/for-teachers).

## Preview

Click the preview button to open the activity as learners see it.
