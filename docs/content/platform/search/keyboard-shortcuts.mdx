# Command Palette and Keyboard Shortcuts

Learners can move around a LearnHouse organization without a mouse. The command palette searches and jumps to pages, and single-key shortcuts handle the common actions on each page.

Press <kbd>?</kbd> on any learner page to open the **Keyboard shortcuts** sheet. It lists every shortcut that works on the page you are on, grouped as **Everywhere**, **Go to** and **On this page**.

<Callout type="info">
Shortcuts are ignored while you are typing in a text field, a select or the editor. Shortcuts that use <kbd>⌘</kbd>, <kbd>Ctrl</kbd> or <kbd>Alt</kbd> are left to the browser, except the palette shortcut.
</Callout>

## Command palette

Open the palette with <kbd>⌘</kbd> <kbd>K</kbd> on macOS, <kbd>Ctrl</kbd> <kbd>K</kbd> on Windows and Linux, or <kbd>/</kbd>. You can also click **Search** in the top menu.

Before you type, the palette shows:

- **Actions**: the shortcuts available on the current page (for example **Start course** on a course page).
- **Go to**: the pages of your organization, such as Home, Courses, Library, Podcasts, Communities, Playgrounds, Store, Progress, Boards, Copilot and your account pages. A page only appears when the feature is turned on for the organization and you are allowed to open it.

Type 3 characters or more to search content. Results are grouped as **Courses**, **Lessons**, **Folders**, **Communities**, **Discussions**, **Playgrounds**, **Podcasts** and **Members**, and **See all results** opens the full [search page](/platform/search).

| Key | Action |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Navigate |
| <kbd>Enter</kbd> | Open |
| <kbd>⌘</kbd>/<kbd>Ctrl</kbd> <kbd>Enter</kbd> | Open in a new tab |
| <kbd>Esc</kbd> | Close |

## Everywhere

| Key | Action |
| --- | --- |
| <kbd>?</kbd> | Open the keyboard shortcuts sheet |
| <kbd>/</kbd> | Open search |
| <kbd>⌘</kbd>/<kbd>Ctrl</kbd> <kbd>K</kbd> | Open search |
| <kbd>p</kbd> | Play or pause the podcast player, when one is open |

## Go to

"Go to" shortcuts are two keys pressed one after the other: press <kbd>g</kbd>, then the second key within about a second.

| Keys | Page |
| --- | --- |
| <kbd>g</kbd> then <kbd>h</kbd> | Home |
| <kbd>g</kbd> then <kbd>c</kbd> | Courses |
| <kbd>g</kbd> then <kbd>l</kbd> | Library |
| <kbd>g</kbd> then <kbd>p</kbd> | Podcasts |
| <kbd>g</kbd> then <kbd>m</kbd> | Communities |
| <kbd>g</kbd> then <kbd>y</kbd> | Playgrounds |
| <kbd>g</kbd> then <kbd>s</kbd> | Store |
| <kbd>g</kbd> then <kbd>t</kbd> | Progress (your trail) |
| <kbd>g</kbd> then <kbd>b</kbd> | Boards |
| <kbd>g</kbd> then <kbd>a</kbd> | Copilot |
| <kbd>g</kbd> then <kbd>u</kbd> | Account settings |

A chord only exists when its page is available to you. If the organization has turned off podcasts, for example, <kbd>g</kbd> <kbd>p</kbd> does nothing.

## Lists and catalogs

These work on the home page, the course catalog, the library and its folders, podcasts, communities, playgrounds, boards, your progress page and the search page.

| Key | Action |
| --- | --- |
| <kbd>j</kbd> or <kbd>↓</kbd> | Next item |
| <kbd>k</kbd> or <kbd>↑</kbd> | Previous item |
| <kbd>Enter</kbd> | Open selected item |
| <kbd>]</kbd> | Next page |
| <kbd>[</kbd> | Previous page |

## Course page

| Key | Action |
| --- | --- |
| <kbd>s</kbd> | Start course, or continue where you left off |
| <kbd>e</kbd> | Expand or collapse all chapters |

## Lesson page

| Key | Action |
| --- | --- |
| <kbd>j</kbd> or <kbd>→</kbd> | Next lesson |
| <kbd>k</kbd> or <kbd>←</kbd> | Previous lesson |
| <kbd>]</kbd> | Next chapter |
| <kbd>[</kbd> | Previous chapter |
| <kbd>m</kbd> | Mark lesson complete, or unmark it |
| <kbd>f</kbd> | Toggle focus mode |
| <kbd>Esc</kbd> | Exit focus mode |
| <kbd>Space</kbd> | Play or pause video |
| <kbd>c</kbd> | Back to course |

In right-to-left languages, the arrow keys for next and previous lesson are swapped to follow the reading direction.
