# AI

LearnHouse has AI features for both teachers and learners. They work from your own course content, so answers and generated material are specific to what you teach.

- **For learners**: an **Ask AI** chat on each activity, and **Copilot** and other agents in [Messages](/platform/messages), which answer questions across your courses with citations. See [AI for Students](/platform/ai/for-students).
- **For teachers**: the AI Editor, the AI Course Creator, Magic Blocks, quiz, scenario and assignment task generation, images, narrated audio, video captions and chapters. See [AI for Teachers](/platform/ai/for-teachers).

## Turning AI on

AI is controlled per organization in the **AI** tab of the [Organization Settings](/platform/organizations/settings). Only admins can change it:

| Setting | What it does |
| --- | --- |
| **Enable AI Features** | Turns every AI feature on or off for the organization. |
| **AI Copilot** | Turns on Copilot and the other [agents](/platform/messages#agents) in Messages. They answer from your indexed course material, with citations. |

The editor and activity AI features (**AI-powered content editor assistance** and **AI learning activity interactions**) are always on while AI is enabled.

### Indexing courses for AI

Copilot and the other agents answer from an index of your course content. In a course's header in the dashboard, click **Index for AI** to index it. The button then shows **Indexed**, and the course is re-indexed automatically when its activities change.

<Callout>
On self-hosted instances AI also has to be configured on the server. LearnHouse supports several AI providers (Google Gemini is the default). Image generation and text to speech always use Google. See [AI Setup](/self-hosting/configuration/ai-setup).
</Callout>

## AI credits

AI usage is counted in AI credits per organization. Every AI action reserves its credits before it runs and gives them back if it fails.

On LearnHouse Cloud, each plan includes a number of credits per billing cycle:

| Plan | Credits |
| --- | --- |
| Free | 20 |
| Personal | 500 |
| Standard | 1000 |
| Pro | 2000 |
| Enterprise | Unlimited |

You can buy extra credits as a monthly add-on. The dashboard home and the **Usage** tab of the organization settings show how many are left, under **AI Credits**. When credits run out, AI actions are refused until the next cycle or until you add more.

Self-hosted instances have no credit limit. Usage is still counted.

### Cost per action

| Action | Credits |
| --- | --- |
| **Ask AI** message on an activity | 1 |
| Agent reply in Messages (Copilot or your own agents) | 2 |
| AI Editor message | 1 |
| Magic Block generation or change | 3 |
| Quiz block generation | 2 |
| Scenarios generation | 2 |
| Assignment task generation | 3 |
| AI Course Creator: plan, change to the plan, or one activity | 1, or 3 with the "pro" model |
| Image generation | 5 |
| Audio script | 1 |
| Audio narration | 3 |
| Video captions | 1 per started 10 minutes of audio, plus 1 per translated language |
| Video chapters | 1 |
| Playground generation | 3 |
| Board AI Playground generation | 3 |
| **Organize with AI** when building a course from files | 1 |
