# Certifications

A course can award a certificate to learners who complete it. Each certificate has a unique ID and a public page anyone can use to check it is genuine.

<Callout>
On LearnHouse Cloud, certifications need the Pro plan or higher. Setting one up also needs permission to create certifications in the organization.
</Callout>

## Setting up a certificate

Open the course in the dashboard and go to the **Certification** tab. Click **Enable Certification**, then fill in:

| Field | Notes |
| --- | --- |
| **Certification Name** | Up to 100 characters. |
| **Certification Description** | Up to 500 characters. |
| **Certification Type** | Course Completion (default), Achievement Based, Assessment Based, Participation, Skill Mastery, Professional Development, Continuing Education, Workshop Attendance or Specialization. |
| **Certificate Pattern** | The background design: Royal, Tech, Nature, Geometric, Vintage, Waves, Minimal, Professional (default), Academic or Modern. |
| **Instructor Name (Optional)** | Printed on the certificate. |

The **Certificate Preview** updates as you edit. The certificate also shows your organization's logo and a QR code that links to its verification page.

## When a certificate is awarded

A learner earns the certificate when both are true:

- Every activity in the course is complete.
- Every graded assignment in the course is graded and passed at its passing threshold. [Formative](/platform/assignments/formative) assignments only need to be handed in.

A course without assignments awards the certificate on completion alone. If an assignment is still waiting for a grade, the certificate is issued once it is graded and passed.

## What learners get

At the end of the course, learners see **Your Certificate**, with **Download Certificate PDF** and **Verify Certificate**. All their certificates are listed under **My Certificates** on their [Progress page](/platform/courses/trails).

## Verifying a certificate

Each certificate has an ID like `AB-20261102-1a2b-3c4d5e6f`: two letters, the award date, part of the learner's ID and a random suffix. Its verification page at `/certificates/{id}/verify` shows the certificate ID, course name, certification type, award date and instructor. Share that link, or the QR code on the certificate, with anyone who needs to check it.

## Revocation

A certificate is revoked automatically when the learner no longer meets the conditions: an assignment is re-graded below its passing threshold, rejected, or reset for a retry. It is issued again once they pass. Admins can also revoke a certificate through the admin API with an API token.

Every revocation fires a `certificate_revoked` [webhook](/platform/automations/webhooks) event.
