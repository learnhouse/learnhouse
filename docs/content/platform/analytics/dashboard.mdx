# Analytics Dashboard

Open **Analytics** in the dashboard sidebar to see organization-wide numbers. The page has three tabs, **Overview**, **Features** and **Advanced**, and a time range picker with **7d**, **30d**, **90d** and **12m** (30 days by default). The range applies to every widget that uses one. Admins also see how long data is kept (for example "1 year"), which links to the [analytics settings](/platform/analytics#settings).

<Callout type="info">
The dashboard needs the Enterprise Edition when self-hosted, or an eligible plan on LearnHouse Cloud. See [Analytics](/platform/analytics) for availability.
</Callout>

## Overview

<img src="/img/pages/analytics/analytics-overview.webp" alt="The Overview tab of the Analytics dashboard with Live Now, Signups, Enrollments, Completions, Submissions and the Daily Active Users chart" width={1600} height={900} style={{ borderRadius: 10 }} />

### Headline numbers

| Widget | What it shows |
| --- | --- |
| **Live Now** | Users active in the last 5 minutes. Click it to see each user's current page, device, country and last seen time. |
| **Visitors** | Unique visitors in the selected range, with their page views. |
| **Signups** | New registrations in the range. Click it for the list with email and signup method. |
| **Enrollments** | Course enrollments in the range. Click it for the list. |
| **Completions** | Course completions in the range. Click it for the list. |
| **Submissions** | Assignment submissions in the range. |
| **Traffic** | Visitors and signed-in learners per day. Hover a day for its device split, top countries and top referrer. |
| **Countries** / **Top Countries** | Where visitors come from. Needs a CDN or proxy that sets a country header, such as Cloudflare. |
| **Devices** | Split between **Desktop**, **Mobile** and **Tablet**. |
| **Top Referrers** | The sites that send you traffic. |

### Core widgets

| Widget | What it shows |
| --- | --- |
| **Enrollment Funnel** | **Page Views**, **Course Views**, **Enrollments** and **Completions**, with conversion rates for **View → Enroll**, **Enroll → Complete** and **Page → Complete**. |
| **Top Courses** | Your most viewed courses, with views, enrollments and completions. |
| **Activity Engagement** | The lessons learners spend the most time on, with type and average time. |

## Features

The **Features** tab shows how each part of LearnHouse is used in the selected range.

| Section | What it shows |
| --- | --- |
| **Feature adoption** | People using each feature (learning, assessments, community, AI assistant, podcasts, boards, playgrounds, learning paths, search, messaging, library and certificates), compared with the previous period. Click a feature to chart it. |
| **Video engagement** | How far viewers get through each video. |
| **Podcast listening** | Plays per episode and how many listen to the end. |
| **Assessments** | Submissions, pass rate and average score for assignments, quizzes and code exercises. |
| **Community activity** | Discussions, comments, reactions and upvotes per day, and the top communities. |
| **AI assistant** | Messages sent, people using the assistant and where it is used. |
| **Sign-up and sign-in** | Sign-ups, joins, logins and invites. |
| **Email nudges** | Nudges sent and how many people came back within 7 days. |
| **Learning paths**, **Boards and playgrounds**, **Library** | Use of each of these features. |
| **Content creation** | Courses created and published, activities, boards, playgrounds and podcast episodes your team made. |

## Advanced

The **Advanced** tab adds deeper widgets. Each one shows a plan badge and an upgrade link when your organization is not eligible.

<img src="/img/pages/analytics/analytics-advanced.webp" alt="The Advanced tab with Org Growth Trend, New vs Returning Users, Cohort Retention and Peak Usage Hours" width={1600} height={900} style={{ borderRadius: 10 }} />

| Widget | Description |
| --- | --- |
| **Org Growth Trend** | Weekly signups, enrollments, completions |
| **New vs Returning Users** | Growth vs retention health |
| **Cohort Retention** | % users active after signup week |
| **Peak Usage Hours** | Event volume by day and hour |
| **Course Dropoff** | Where users stop per course |
| **Time to Completion** | Median days to complete each course |
| **Completion Velocity** | Avg days between activity completions |
| **Content Type Effectiveness** | Completion rate by activity type |
| **Course Effectiveness Matrix** | Activity count vs completion rate (sized by enrollments) |
| **Community Correlation** | Completion rate: discussors vs non-discussors |
| **Learner Engagement Score** | Top learners by composite engagement |
| **User Progress Snapshot** | Users at each completion bracket per course |
| **Grade Distribution** | Assignment grade histogram |
| **Certification Rate** | % of completers who claim certificates |
| **Search Effectiveness** | Top queries and zero-result rate |

**Time to Completion** always covers the last 180 days, whatever the range picker says.

## Exporting

Click **Export** in the page header and choose **Download JSON** or **Download CSV**. The file holds the data behind the tab you are on (Overview, Features or Advanced) for the selected range, and is named like `analytics_30d.csv`. Exporting needs the same admin rights and plan as viewing the widgets.

## Data freshness

Results are cached for up to 1 minute on the overview and 5 minutes on the advanced tab. **Live Now** is always live.
