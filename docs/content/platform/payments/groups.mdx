# Payment Groups (Legacy)

Payment groups used to bundle courses so that several offers could share them. Products now hold their content directly, and you can mix any type of content in one product, so you don't need groups anymore.

Existing groups keep working: the content in a group was copied onto each product that used it, and buyers synced into a group's user groups are still added and removed as before. To change what a product unlocks, edit the product.
