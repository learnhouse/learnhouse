# Resources

The client groups its methods by resource. This page covers the content a catalog or a lesson page reads; the rest
has its own page:

| Page | Resources |
| --- | --- |
| [Accounts and sign-in](/developers/sdk/accounts) | `auth`, `auth.mfa`, `users`, `orgs.listMine` / `join` / `leave` |
| [Progress, assignments and certificates](/developers/sdk/learning) | `trail`, `assignments`, `certificates`, `paths`, `notes`, `calendar`, `TrailStore` |
| [Communities, notifications and groups](/developers/sdk/community) | `communities`, `discussions`, `notifications`, `usergroups` |
| [Admin API](/developers/sdk/admin) | `admin.*` (server, API token) |
| [Embed sessions](/developers/sdk/embed-sessions) | `embed.createSession` |
| [Agent API](/developers/agent-api) | `agent` (Enterprise) |

Conventions for every method:

- The last argument is `options`: `signal`, `headers`, `timeoutMs`, `retry`, `skipAuth`. Methods with their own options
  (`page`, `limit`, `lang`…) take them in the same object.
- It resolves with the typed response data, or rejects with a [`LearnHouseError`](/developers/sdk/requests#errors)
  (an aborted `signal` rejects with the platform's `AbortError`).
- Ids are uuids with their prefix (`course_…`, `activity_…`), except where a method says "numeric id".
- **Auth** lists the [modes](/developers/sdk/auth-modes) the API accepts. "Anyone" means anonymous callers too
  (public content only).

## Organizations

| Method | Endpoint | Returns | Auth |
| --- | --- | --- | --- |
| `orgs.get(slug)` | `GET /api/v1/orgs/slug/{org_slug}` | `Organization` | Anyone, session, embed. **Not API tokens** |
| `orgs.getByUuid(uuid)` | `GET /api/v1/orgs/uuid/{org_uuid}` | `Organization` | Anyone, session, embed. **Not API tokens** |
| `orgs.resolveDomain(domain)` | `GET /api/v1/orgs/resolve/domain/{domain}` | `{ org_id, org_slug, org_uuid }` | Anyone (404 for an unknown domain) |

You need the org's numeric `id` for several learner methods (`trail.getForOrg(org.id)`, `paths.list(org.id)`…):

```ts
const org = await lh.orgs.get('your-school')
const trail = await lh.trail.getForOrg(org.id!)
```

With an API token, `orgs.get` answers `403`; `auth.me()` returns the token's `org_id` and `org_slug` instead.

## Courses

| Method | Endpoint | Returns | Auth |
| --- | --- | --- | --- |
| `courses.list(orgSlug, { page, limit, includeUnpublished })` | `GET /api/v1/courses/org_slug/{org_slug}/page/{page}/limit/{limit}` | `Course[]` | Anyone, session, API token |
| `courses.listAll(orgSlug, { pageSize, includeUnpublished })` | The same, page after page | async iterator of `Course` | Anyone, session, API token |
| `courses.count(orgSlug)` | `GET /api/v1/courses/org_slug/{org_slug}/count` | `number` | Anyone, session, API token |
| `courses.search(orgSlug, query, { page, limit })` | `GET /api/v1/courses/org_slug/{org_slug}/search` | `Course[]` | Anyone, session, API token |
| `courses.get(courseUuid)` | `GET /api/v1/courses/{course_uuid}` | `Course` | Anyone, session, API token, embed |
| `courses.getById(courseId)` | `GET /api/v1/courses/id/{course_id}` (numeric id) | `Course` | Anyone, session, API token, embed |
| `courses.getMeta(courseUuid, { slim, withUnpublishedActivities })` | `GET /api/v1/courses/{course_uuid}/meta` | `CourseMeta`: the course with chapters and activities | Anyone, session, API token, embed |
| `courses.listUpdates(courseUuid)` | `GET /api/v1/courses/{course_uuid}/updates` | `CourseUpdate[]` (announcements) | Anyone, session, API token |

```ts
const page = await lh.courses.list('your-school', { page: 1, limit: 12 })
const found = await lh.courses.search('your-school', 'python')
const course = await lh.courses.getMeta('course_…', { slim: true }) // slim: no activity content, enough for navigation

for (const chapter of course.chapters) {
  console.log(chapter.name, chapter.activities?.map((a) => a.name))
}
```

`listAll` yields every course of the org and stops after the first short page, so it never fetches past the end.
`pageSize` defaults to 100, the API's maximum. Anonymous callers and learners see published courses they may open;
`includeUnpublished` only helps users who can edit them. `trail` runs and steps carry numeric ids: use
`courses.getById()` and `activities.getById()` to turn them back into objects.

## Activities

| Method | Endpoint | Returns | Auth |
| --- | --- | --- | --- |
| `activities.get(activityUuid)` | `GET /api/v1/activities/{activity_uuid}` | `Activity`, including `content` | Anyone, session, API token, embed |
| `activities.getById(activityId)` | `GET /api/v1/activities/id/{activity_id}` (numeric id) | `Activity` | Anyone, session, API token, embed |
| `activities.listForChapter(chapterId)` | `GET /api/v1/activities/chapter/{chapter_id}` | `Activity[]` | Anyone, session, API token |
| `activities.resolve({ activityId })` | `GET /api/v1/activities/{activity_uuid}` (id with or without `activity_`) | `Activity` | Like `get` |
| `activities.resolve({ courseId, activityName })` | Name lookup in `GET /api/v1/courses/{course_uuid}/meta?slim=true`, then `get` | `Activity` | Like `get` |

An activity's `content` is the document [`<LearnHouseActivity>`](/developers/react) renders.

### Load an activity to render

`resolve` loads an activity the way `<LearnHouseActivity>` does: by id, or by name inside a course. Ids work with or
without their prefix, so you can paste them from a LearnHouse URL (`/course/<id>/activity/<id>`). Names match without
regard to case, spacing or punctuation.

```ts
const byId = await lh.activities.resolve({ activityId: 'activity_…' })
const byName = await lh.activities.resolve({ courseId: 'course_…', activityName: 'How payouts work' })
```

An unknown name throws a `LearnHouseError` with status `404` and code `ACTIVITY_NOT_FOUND`. If you already have the
course meta, pass it as `courseMeta` and the name lookup skips its own request.

### Fetch on the server, render in the browser

Load the activity on your server with an API token, then pass it to the component as `activity`. The browser never
calls the LearnHouse API, so you need no CORS setup, and the token stays on your server.

```tsx title="app/lessons/[name]/page.tsx"
import { createClient } from '@learnhouse/sdk'
import { LearnHouseActivity } from '@learnhouse/react'

const lh = createClient({ baseUrl: process.env.LEARNHOUSE_URL!, token: process.env.LEARNHOUSE_TOKEN! })

export default async function Lesson({ params }: { params: Promise<{ name: string }> }) {
  const { name } = await params
  const activity = await lh.activities.resolve({ courseId: 'course_…', activityName: decodeURIComponent(name) })
  return <LearnHouseActivity activity={activity} courseId="course_…" baseUrl={process.env.LEARNHOUSE_URL} />
}
```

Keep `courseId` and `baseUrl` on the component: media blocks use them to build image and video URLs.

## Search

| Method | Endpoint | Returns | Auth |
| --- | --- | --- | --- |
| `search.org(orgSlug, query, { page, limit })` | `GET /api/v1/search/org_slug/{org_slug}` | `SearchResult` | Anyone, session, API token (`search` right) |
| `search.orgPages(orgSlug, query, { pageSize })` | The same, page after page | async iterator of `SearchResult` | Same |

The query must be 3 to 200 characters (`422` otherwise). Each result type (courses, activities, users…) is paged on
its own. `orgPages` yields one `SearchResult` per page and stops once every type comes back shorter than `pageSize`
(default and maximum 50):

```ts
for await (const page of lh.search.orgPages('your-school', 'payouts')) {
  console.log(page.courses.length, page.activities?.length)
}
```

Search is rate limited per user. If you hit the limit, the SDK waits for the time the API asks, within `maxDelayMs`.
See [Rate limits](/developers/sdk/requests#rate-limits).

An episode's `audio_file` is a file name; build its URL with `lh.media` (below).

## Instance

`instance.info()` → `InstanceInfo` (`tenancy`, `default_org_slug`, `frontend_domain`, `top_domain`, `mode`,
`license_locked`). `GET /api/v1/instance/info`. **Auth:** anyone. Useful to find the default org of a single-org
instance:

```ts
const { default_org_slug } = await lh.instance.info()
```

## Media URLs

Course thumbnails, block images, videos and files live under your instance's `content/` path. `lh.media` builds those
URLs exactly the way the LearnHouse web app does (it is the same code):

```ts
const org = await lh.orgs.get('your-school')
const course = await lh.courses.get('course_…')

const thumbnail = lh.media.getCourseThumbnailMediaDirectory(org.org_uuid!, course.course_uuid!, course.thumbnail_image!)
```

If files are served from somewhere else (a CDN or bucket), pass `mediaUrl` to `createClient`. The helpers also exist
standalone, without a client:

```ts
import { media } from '@learnhouse/sdk'

media.getUserAvatarMediaDirectory({ baseUrl: 'https://learn.your-school.com' }, userUuid, fileId)
```
