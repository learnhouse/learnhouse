# Contributing to LearnHouse

Thank you for your interest in contributing to LearnHouse. Bug fixes, new features, and documentation improvements are all welcome.

## Getting Started

1. **[Set up your development environment](/developers/contributing/dev-environment)**: Get a local instance of LearnHouse running using the LearnHouse CLI.
2. **[Review the contribution guidelines](/developers/contributing/guidelines)**: Understand our workflow, code style, and expectations for pull requests.

## Finding Work

The best place to start is the [LearnHouse GitHub issues](https://github.com/learnhouse/learnhouse/issues) page. Look for issues labeled:

- **`help wanted`**: Issues where community contributions are especially welcome.
- **`good first issue`**: Smaller, well-scoped tasks ideal for first-time contributors.

If you have an idea for a new feature, start a [Discussion in the Ideas category](https://github.com/learnhouse/learnhouse/discussions/categories/ideas) to agree on it with the maintainers before starting work. See [CONTRIBUTING.md](https://github.com/learnhouse/learnhouse/blob/dev/CONTRIBUTING.md) in the repository.

## Questions

If you have questions about contributing, feel free to open a discussion on the [GitHub repository](https://github.com/learnhouse/learnhouse) or reach out to the maintainers through the issue tracker.
