## Quickstart

<Steps>

### Install

```bash
npm install @learnhouse/react
```

React 18 or 19 is required. Everything else the blocks need comes with the package.

### Import the component and its stylesheet

```tsx
import { LearnHouseActivity } from '@learnhouse/react'
import '@learnhouse/react/styles.css'
```

The stylesheet is LearnHouse's own, scoped under `.lh-activity`, so it never touches the rest of your page.

### Render an activity

```tsx
export function Lesson() {
  return (
    <LearnHouseActivity
      baseUrl="https://learn.your-school.com"
      activityId="activity_0b3c…"
      courseId="course_9f2a…"
    />
  )
}
```

`baseUrl` is the address of your LearnHouse instance (its API). Ids are the full uuids, with their `activity_` and
`course_` prefixes. You can copy them from the API or the activity's URL.

</Steps>

## Four ways to say what to render

<Tabs items={['By id', 'By name', 'From an activity', 'From JSON']}>
  <Tabs.Tab>
    ```tsx
    // Passing courseId as well loads the course in parallel (faster).
    <LearnHouseActivity activityId="activity_…" courseId="course_…" />
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```tsx
    // Looks the activity up by name inside the course (case-insensitive).
    <LearnHouseActivity activityName="How payouts work" courseId="course_…" />
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```tsx
    // An activity you already fetched, for example on the server with @learnhouse/sdk.
    <LearnHouseActivity activity={activity} orgId="org_…" courseId="course_…" />
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```tsx
    // A document as LearnHouse stores it. No network calls for the content itself.
    <LearnHouseActivity content={doc} orgId="org_…" courseId="course_…" />
    ```
  </Tabs.Tab>
</Tabs>

`courseId` and `orgId` tell image, video, audio and PDF blocks where their files live. Without them, text blocks still
render, but media blocks can't find their files. With `activity`, a missing `courseId` is looked up from the activity, and
a missing `orgId` from the course once it loads; passing both lets media load from the first render.

## Share one setup with a provider

Wrap your app (or a layout) in `LearnHouseProvider` once. Every activity below shares the client, the signed-in user and
your defaults.

```tsx
import { LearnHouseProvider, LearnHouseActivity } from '@learnhouse/react'

export function App({ session }: { session: { accessToken: string } }) {
  return (
    <LearnHouseProvider
      baseUrl="https://learn.your-school.com"
      getToken={() => session.accessToken}
      theme={{ accent: '#7c3aed', fontFamily: 'Inter, sans-serif' }}
      locale="fr"
      onEvent={(event) => analytics.track(`lesson_${event.type}`, event)}
    >
      <LearnHouseActivity activityId="activity_…" courseId="course_…" />
    </LearnHouseProvider>
  )
}
```

<Callout type="warning">
  In the browser, pass the signed-in learner's own access token (or nothing, for public courses). Never pass an
  `lh_` API token to a browser: it acts on your whole org. Keep those on your server with the
  [SDK](/developers/sdk/authentication).
</Callout>

## Frequently asked questions

### What is @learnhouse/react?

`@learnhouse/react` is an open-source (MIT) React component library that renders LearnHouse course content inside your
own React app. `<LearnHouseActivity>` shows pages, quizzes, flipcards, scenarios, code playgrounds, math, video and PDFs
with LearnHouse's own blocks, themed to match your product.

### Which React versions and frameworks are supported?

React 18 and 19. It works in [Next.js (App Router) and Vite](/developers/react/frameworks), and in any other React
setup that can import a stylesheet. `LearnHouseActivity` is a client component, so you can use it straight from a
Next.js Server Component page.

### Do I need a LearnHouse account to use the React component?

You need a LearnHouse instance to hold the courses: a free LearnHouse Cloud organization or a self-hosted one. Public
courses render without a token. To save progress as a learner, pass a short-lived session minted on your server: see
[Signed-in learners](/developers/react/learners).

### Does it work in React Native?

No. The component renders with the DOM. In a React Native or Expo app, show lessons in a `WebView` pointed at the
[embed URL](/developers/embed), or build native screens with the [SDK](/developers/sdk/react-native).

### Can I change how blocks look?

Yes. Pass a `theme` (accent, font, radius, content width), or replace any block with your own component through the
`components` prop. See [Customization](/developers/react/customization).
